# Listing Guides — Screenshots

This folder holds optional screenshot assets surfaced on `guides.html`.

Each platform has a subfolder; the guides page references specific
filenames so the screenshots show up in order without further config.

Suggested file names per platform (page references these paths in
the screenshot placeholder blocks):

- `ebay/01-listing-form.png`, `02-pricing.png`, `03-shipping.png`
- `poshmark/01-list-item.png`, `02-cover-shot.png`, `03-price.png`
- `mercari/01-list.png`, `02-pricing.png`
- `depop/01-listing.png`
- `etsy/01-listing-form.png`, `02-tags.png`
- `facebook-marketplace/01-create.png`, `02-category.png`, `03-pricing.png`
- `craigslist/01-new-post.png`, `02-photos.png`
- `offerup/01-post-item.png`, `02-local-pickup.png`
- `nextdoor/01-post.png`

Recommended dimensions: 1000–1200 px wide, PNG, optimize for web.
The page styles will render them inline once they exist; right now
each section shows a small `📸 Add yours: ...` placeholder so the
page reads cleanly even with no images.
